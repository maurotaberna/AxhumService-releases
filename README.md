# Axhum Service — Descargas

Programa de escritorio para talleres de reparación de celulares: recepción de
equipos, seguimiento por estados, mostrador de venta, caja y reportes.
Funciona sin internet, en Windows.

Este repositorio solo contiene los **instaladores oficiales**. El código
fuente es privado.

## Descargar

La última versión está en **[Releases](../../releases/latest)**.

Cada versión trae:

- El instalador (`.exe`)
- `SHA256SUMS.txt`, para comprobar que el archivo no se alteró en el camino
- Instrucciones de instalación

## Prueba gratuita

El programa se puede usar entero durante **15 días**, sin pagar nada. Para
seguir usándolo después, hay que activarlo con una clave que emite Axhum Tech,
atada a esa computadora.

## Windows puede avisar "Editor desconocido"

El instalador todavía no tiene firma digital, así que Windows SmartScreen
puede mostrar una advertencia azul al ejecutarlo. Esto es esperable en un
programa nuevo sin firma — **no** significa que tenga un virus.

Si aparece ese aviso: tocá **"Más información"** y después **"Ejecutar de
todas formas"**. No hace falta desactivar el antivirus ni ningún otro control
de seguridad de Windows para instalar el programa.
